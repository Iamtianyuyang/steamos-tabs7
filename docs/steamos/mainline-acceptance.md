# 完整 6.18 移植验收

目标保持为 SM-T870 / gts7lwifi rev7 上的原生 Linux 6.18 LTS 与 SteamOS ARM，
包括 Game Mode 和 Desktop Mode。4.19 是可恢复的对照环境，不是主线移植的完成条件。
项目版本仍为 `0.0.001`。

## 证据规则

- 每项必须记录实际运行内核、镜像哈希、启动标识和原始日志。
- 构建成功、设备节点存在、进程 active、模式枚举与用户实际可见/可操作分别验收。
- 4.19 的结果不能直接计入 6.18；诊断工具的测试也不能代替被诊断硬件的验收。
- 显示以全屏测试图、实际内容、持续扫描及重启复现为准；空闲时软件 vblank IRQ
  计数不增长不单独证明硬件停止扫描，必须结合实时硬件计数核对。
- 修复涉及显示、触摸、会话或电源交接时，要回归概览、键盘、锁屏和唤醒。
